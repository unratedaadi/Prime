# PRIME interface

A personal Mac assistant with a clean JARVIS-inspired cockpit. Keep the navy canvas (#060d15), cyan accent (#67e2f3), pale foreground (#d8edf4), muted labels (#88a5b5), and teal success (#69e5be). Use Avenir Next for interface text and system monospace for small status labels.

The central animated reactor is the signature. Its labels reflect real local-helper and voice state; do not invent system measurements. The Command Center may show verified system memory/storage and attached-display state. Keep four navigation views: command center, tools and routines, activity, and settings. Preserve all existing confirmation and macOS permission boundaries. Start the local helper automatically on launch and retry setup every five seconds without replaying actions or overriding pause.

Reuse the existing modal, buttons, form labels, notices, and local preference storage. Maintain keyboard focus indicators, responsive layouts, readable contrast, and reduced-motion support. The command field is the primary interaction. Integration setup and permissions live under Settings. A future theatre mode may occupy an external display, but it must show only actual local status and never imply document, calendar, messaging, or monitoring access that the user has not enabled.
